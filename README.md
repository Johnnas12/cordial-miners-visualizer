# Cordial Miners visualizer

A static, interactive explanation of Cordial Miners. Open [index.html](index.html) in a browser; no build step or local server is needed.

## Modules

1. Three-round eventual-synchrony wave and tau ordering.
2. Cordial dissemination and delayed-tip handling.
3. Equivocation detection and exclusion.
4. Illustrative PoR-weighted quorum decisions. The sample weights are not calculated by the PoR formula; the page uses the strict `> 2/3` active-weight quorum check.
5. Four-observer replay generated by `cordial-miners-core`'s Rust simulation. This is not a live f1r3node feed or a PoR-weighted run.

## Publish on GitHub Pages

In this repository's **Settings > Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)**, then save. GitHub Pages serves `index.html` and the other files directly. The expected URL is `https://johnnas12.github.io/cordial-miners-visualizer/` once Pages finishes publishing.

## Refresh the Rust trace

Run this from the `blocklace` repository after changing its simulation trace exporter. Set `TRACE_SITE_DIR` to wherever you cloned this visualizer:

```sh
cargo run -p cordial-miners-core --bin export_four_node_trace
TRACE_SITE_DIR=/path/to/cordial-miners-visualizer
cp docs/cordial-miners/generated/four-node-trace.js "$TRACE_SITE_DIR/generated/four-node-trace.js"
```

The `generated/four-node-trace.js` file is committed here so the replay works on GitHub Pages and from local files without a build service. The exporter lives in `crates/cordial-miners-core/src/simulation/trace.rs`.
